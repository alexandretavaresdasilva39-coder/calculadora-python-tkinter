# Calculadora Gráfica em Python (Tkinter)

Aplicação de calculadora desenvolvida em Python utilizando a biblioteca gráfica Tkinter.

## Funcionalidades
- Operações de soma, subtração, multiplicação e divisão.
- Tratamento de exceções para divisão por zero e sintaxe inválida.
- Interface responsiva com grelha adaptável.

## Tecnologias
- Python 3
- Tkinter
